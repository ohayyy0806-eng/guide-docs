# Badge-Small

06 · Indicators · Figma `325:21447` · 3변이 — 명세: `components/06-indicators/badge-small.md`

:::tip 상태: 완료

특정 요소의 상태, 속성, 혹은 분류를 시각적으로 강조하고 싶을 때 다양한 색상으로 활용할 수 있습니다.
사용자의 시선을 끌어 중요한 정보를 효과적으로 전달하는 데 사용합니다.

## Anatomy

가장 단순한 형태의 배지로, 아이콘 없이 **Container**와 **Label** 두 요소로만 구성됩니다.

|---|---|---|

| ② | Label | `text-body-4-semibold`(12px) 텍스트, 색상은 배경과 짝을 이루는 `*-label` 토큰 |

## Variants

<div className="variant-stage">
  <BadgeSmall variant="blue" />

| Variant | 배경 토큰 | 텍스트 토큰 |
|---|---|---|
| `blue` | `--status-info-bg-strong` | `--status-info-label` |
| `gray` | `--status-neutral-bg-strong` | `--label-normal` |
| `red` | `--status-negative-bg-strong` | `--status-negative-label` |

:::warning
`gray` variant의 라벨만 `--label-normal`(#525256)로 Status 계열 밖입니다 — Badge-Medium의 `gray`
(`--status-neutral-label` #6D7281)보다 진합니다. Figma "Spec" 표에 명시된 **의도된 차이**이며
대비를 6.95:1까지 올립니다.
:::

## Size

높이는 **26px로 고정**되어 있고, 너비는 Label 텍스트 길이에 따라 자동으로 늘어납니다.
가로 폭을 임의로 고정하지 마세요.

## Spacing

Container 좌우에 `--space-08`(8px) padding이 적용됩니다. Label과 Container 사이에 별도의 gap은
없고, 이 padding이 곧 여백 역할을 합니다.

## Usage

특정 요소의 상태, 속성, 혹은 분류를 시각적으로 강조하고 싶을 때 다양한 색상으로 활용할 수 있습니다.
사용자의 시선을 끌어 중요한 정보를 효과적으로 전달하는 데 사용합니다.

| 색상 | 의미 | 예시 |
|---|---|---|
| `blue` (info) | 정보·완료 안내 | "완료", "진행중" 같은 안내성 상태 |
| `gray` (neutral) | 비활성·종료, 중립적인 분류 | 종료된 항목, 부가 태그 |
| `red` (negative) | 오류·반려 | "반려됨", "오류" 같은 부정적 상태 |
