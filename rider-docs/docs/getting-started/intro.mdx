# Rider Design System

솔라쉐어 라이더 앱의 디자인 시스템 가이드입니다. Foundations(컬러·타이포·스페이싱 등 원자적 단위)와
Components(실제 화면에 쓰이는 컴포넌트)로 구성됩니다.

토큰은 Figma 변수에서 직접 추출한 Primitive/Semantic 2계층 구조를 따릅니다. 화면을 만들 때는
항상 **Semantic 토큰**을 기준으로 하고, Semantic에 대응이 없는 예외적인 경우에만 Primitive를
직접 참조하세요.

## 구성

- **Foundations** — Color, Typography, Grid, Radius, Border, Elevation
- **Components** — Text Inputs, Actions, Selection Controls, Navigation, Data Display,
  Indicators, Disclosure, Overlay (8개 카테고리)
